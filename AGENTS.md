quang.design is a personal portfolio for a design engineer, built with SvelteKit.

Use pnpm.

Typecheck with `pnpm check`. Lint with `pnpm lint`. Unit tests are `pnpm test`. `pnpm test:lock` checks design-page geometry against a dev server on port 5173.

Design page conventions live in [docs/design-pages.md](docs/design-pages.md).
